# Kết quả thực nghiệm thăm dò (Exploratory Results)

Thư mục này lưu trữ các kết quả từ lần chạy thử nghiệm thăm dò trước đó bằng `run_main.py` và `run_extra.py` (cấu hình nhẹ: $R=100$ snapshot, $300$ lần đánh giá IC, $k$ đến $20$, có cả mô hình Weighted Cascade `wc`).

**Lưu ý quan trọng:**
- Đây là các kết quả thăm dò ban đầu, **không dùng để trích dẫn trong báo cáo chính thức**.
- Kết quả chính thức phục vụ báo cáo nằm trực tiếp tại thư mục `results/` (các file tiền tố `plan_*`).
- Nếu chạy lại `run_main.py`, `run_extra.py` hoặc `plot.py`, code mặc định sẽ ghi đè trực tiếp ra `results/`.
